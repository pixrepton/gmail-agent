# gmail-agent

Node B runtime for TOP-INSTAL Gmail-first operations.

## Owns

- Gmail signal intake and worker runtime.
- Mailbox/case operational truth.
- Engagement snapshots and operational feed inputs.
- Policy, reconciliation, operator feedback consumption.

## Does Not Own

- HVAC pricing, sizing or `OfferDTO` (`kalk-top`).
- Daszek UI state as source of truth.
- Production deploy by default.
